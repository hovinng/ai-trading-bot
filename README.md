# AI Trading Bot

A simple AI trading bot for the ["Build Your Own AI Trading Bot"](https://aitrading-bot.com/blog/how-to-build-ai-trading-bot) series on [AITradingBot](https://aitrading-bot.com).

## Quick Start

```bash
pip install -r requirements.txt
python bot.py
```

You'll see live BTC/USDT prices with simulated AI predictions every 60 seconds.
